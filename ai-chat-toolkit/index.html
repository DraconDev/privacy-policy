Privacy — AI Chat Toolkit

AI Chat Toolkit stores your data in your browser by default.

The extension has no server, no account, no analytics, no telemetry and no licence check. It interacts with supported AI chat sites in the tabs you use, with your existing session where the site requires one.

What is stored, and where

Extension data is stored locally by default, in your own browser, in chrome.storage.local under the extension's own origin:

What Why
Settings The switches on the options page, and which profile is active.
Profiles The name, instructions, model key, thinking level and web-search preference you wrote.
Folders and prompt collections The names, nesting and auto-file rules you created.
Prompts The title, body and tags you saved.
Per-chat notes The note text you attached to a conversation.
Chat filings (legacy, no longer written) Older builds remembered which conversations were filed into which toolkit chat folder. Chats now file as ordinary browser bookmarks instead; leftover filing entries sit unread in local storage and are never transmitted.
Tracked tasks and run history The title and address of each chat that was working, stuck, failed or finished in a tab you had open, with when it started, last reported, why it failed and how many times it has been retried. When a site shows no title for a chat, the title is up to 60 characters of your first message in it. Live tasks are dropped a day after they were last touched. Completed and failed runs appear in the separate History section for 30 days. You can dismiss live tasks sooner. The task record can include a short error reason derived from a reply. It does not keep the full reply. Turn tracking off on the options page and nothing new is recorded.
Input recall Recent text you typed into a composer, kept per site for the up-arrow recall.
Cross-chat handoff A prepared handoff — up to 12,000 characters of the conversation — carried to the chat site you chose; a receiving page can claim it within 10 minutes.
Usage counters Per-site, per-day counts of staged sends and dressed characters, shown on the launcher badge.
Starred turns Which turns of a conversation you starred on the rail.
Sidebar layout Which sidebar sections you kept open or hid, and which tab you last had showing.
Prompt library storage Whether the library stays in this browser or syncs, as you chose on the options page. The prompts themselves are in the rows above.

Uninstalling the extension removes its local storage. If you enable prompt sync in Settings, your library moves to the browser's built-in sync storage (chrome.storage.sync). Your browser vendor may replicate it to your other devices under your browser's sync settings.

What is read from the page

The extension reads the AI chat page you have open so it can do the thing you asked for:

  • the conversation on screen, to show it in the panel and export it;
  • the history list the site has rendered, to let you file chats;
  • the composer, to put a prompt or a profile's instructions into it;
  • the site's own controls — the model picker, the thinking-level menu, the send and stop buttons — so a profile can set them as if you had clicked.
  • whether a reply is still running on the page (the site's stop control or its progress indicator), and the chat's title, so the Folders tab can list it. The toolkit inspects the newest reply locally to identify error messages.
  • the last thing you asked in the chat, when a failed run is retried: the prompt is read back from the conversation so the same message can be sent again.

The toolkit reads page content only on supported chat sites while the page is open. When you open, re-prompt or retry a tracked chat, it checks the URLs of matching open tabs to find that conversation. It does not read the contents of those tabs for this lookup. It does not read your browsing history, passwords or cookies.

What is written back, and when

The toolkit can change the model and other chat controls as part of applying your selected profile. Profile instructions and prompts you put into a composer go to that chat provider when sent. You can configure a saved prompt to send when you run it or choose to send it yourself.

On ChatGPT, the bulk chat manager offers Archive, Pin and Hide (or "Delete", the button the panel labels with what the site does) on the conversations it lists. Choosing them and pressing the button sends the same request the site itself would, with your own signed-in session: is_archived, is_starred or is_visible on the conversation you selected. Nothing is written until you select a chat and press the button. The result is reported per chat.

A re-prompt, pressed on a stuck chat in the Folders tab, types one fixed sentence into that chat's own message box and sends it, after stopping the stuck reply where the site has a stop control. It never writes over a draft you left there. The sentence is visible in the chat like any message you send.

A failed run is tried again on its own: the extension sends your own prompt a second time, the same message you sent first, read back from the conversation. It does this for an eligible run that produced no usable answer, while Run a failed prompt again on its own is on in Settings. The bounds are fixed: at most three retries a run, fifteen seconds apart, and never for a failure that will not get better on its own — a quota, a rate limit or an expired sign-in is reported to you instead. It never sends over a draft you left in the message box, and never sends while a reply is still running. You can also press Retry on the card yourself, which is not capped.

It requests the browser's bookmark tree to identify folders. The browser provides the full tree, including bookmark URLs, but the toolkit uses, returns and stores only folder metadata (id, title, parent id and path) for the save picker. No bookmark URL from that tree is stored or transmitted. It creates one bookmark when you ask it to save the open chat. That is what the bookmarks permission is for, and the only thing it is used for.

Where requests go

The extension sends no data to its developer, analytics services, licence servers or advertising services. The audit bridge is included only in a dedicated maintainer build for disposable browser profiles.

The extension reads conversation data from ChatGPT's own API with your existing ChatGPT session to support history, exports and message dates. History reads use a fixed page and time budget. A rate limit ends the read, and partial results are identified in the export.

Permissions, and why each one exists

Permission Why
storage The settings and the local catalogue above.
bookmarks Save the open chat when you ask for it, and list your bookmark folders for the save picker.
contextMenus The "Save selection as prompt" right-click item. The highlighted text is saved to your prompt library using its current storage setting.
Host access to the supported AI chat sites The content script that renders the panel has to run on those pages.

There is no tabs, scripting, downloads, alarms, cookies, history, identity or oauth2. Exports are saved with a blob URL and a synthetic click, which needs no permission.
